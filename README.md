# 像素冒险：勇者之旅

一个**医学之外**的作业级小游戏：2D 复古像素横版闯关，纯 HTML5 Canvas 单文件实现，零依赖、双击即玩（Windows 任意浏览器）。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → / A D | 移动 |
| ↑ / W / 空格 | 跳跃（长按跳更高，松开短跳） |
| Enter / 空格 | 开始 / 确认 |
| R | 重玩本关 |
| P / Esc | 暂停 |
| M | 音效开关 |

## 当前版本功能

- 像素勇者：跑动 / 跳跃动画 + 披风与扬尘粒子
- 两个关卡：**1-1 草原入口**、**1-2 幽暗森林**（不同视差背景与配色）
- 金币收集（含弧线币阵与悬浮平台币）、终点旗帜过关
- 手感优化：土狼时间、跳跃缓冲、可变跳跃高度、落地扬尘
- WebAudio 合成音效（跳跃/金币/过关/死亡），M 键静音
- 坠落自动重生（本关金币重置），通关结算（总金币 + 死亡次数）

## 后续功能路线图（架构已预留）

1. **怪物**：实体数组已抽象，加入巡逻怪 / 踩踏消灭
2. **战斗**：攻击判定框 + 击退 + 受击无敌帧
3. **生命值**：心形血条 UI + 受伤扣血 + 补给道具
4. **关卡系统**：关卡选择界面、存档（localStorage）、更多主题（雪地/洞穴）

## 技术说明

- 内部分辨率 480×270（16:9），`image-rendering: pixelated` 放大保持像素颗粒
- 关卡由代码化生成器构建（ground/plat/coinArc 等 helper），保证跳跃可达性（跳高 ≈3.2 格、越沟 ≤4 格）
- UI 文本用 DOM 覆盖层（中文清晰），游戏世界用 canvas（像素颗粒）
- 音效为 WebAudio 实时合成，无音频文件

## 运行

双击 `index.html` 即可（任意现代浏览器）。
